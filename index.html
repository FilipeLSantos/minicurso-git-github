Configuração: Sua Identidade no Git

ASSINATURA DOS COMMITS
$ git config user.name "Seu Nome"
$ git config user.email "iniciais@aluno.ifnmg.edu.br"

Todo commit gravado no Git carrega o autor e o e-mail de quem fez a alteração.

ESCOPO & CONFERÊNCIA
$ git config --local user.email "..."
$ git config --list

Use --local para configurar apenas este projeto, ou liste tudo com git config --list.

Mão na Massa: Corrigindo o Bug

01

Proteger Segredos

$ echo ".env" >> .gitignore

Evite versionar logs, dependências e credenciais sensíveis.

02

Inspecionar Linhas

$ git diff

Revise as linhas alteradas antes de preparar qualquer arquivo.

03

Preparar Arquivos

$ git add nomearquivo

Mova as correções validadas para a área de staging.

04

Gravar Snapshot

$ git commit -m "fix: ..."

Escreva uma mensagem clara descrevendo o que foi resolvido.

Autenticação: Criando o Token & Push

NO GITHUB Gerar Token ↗
Settings › Developer Settings › Personal access tokens › Tokens (classic)
1 Nomeie o token (ex: Minicurso Git)
2 Marque o escopo: repo
3 Copie o token gerado (ghp_...)

O token substitui a senha da sua conta no terminal.

$ git push origin main
